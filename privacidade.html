Política de privacidade do Agendador

Última atualização: 13 de novembro de 2026.

O que é

O Agendador é um aplicativo de uso pessoal. Ele roda apenas no computador do próprio dono e serve para agendar vídeos nos canais do YouTube desse dono. Não há usuários externos.

Quais dados usa

Com a autorização do dono pelo login do Google, o app usa a API do YouTube para: identificar o canal conectado (nome, ID e foto do canal), enviar vídeos, definir título, descrição e horário de publicação, conferir se o vídeo foi publicado e apagar vídeos agendados que o dono cancelar.

Onde os dados ficam

Tudo fica no computador do dono: os posts e o histórico num banco de dados local, e as credenciais de acesso no Chaveiro do macOS. Nenhum dado é enviado para servidores do Agendador (não existem servidores do Agendador). Os dados só são enviados ao próprio Google/YouTube, para fazer o que o dono pediu.

Compartilhamento

O app não vende, não compartilha e não transfere dados para terceiros, e não usa dados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

O dono pode desconectar um canal no próprio app (o que revoga o acesso junto ao Google) ou a qualquer momento em myaccount.google.com/permissions. Remover o app do computador apaga todos os dados locais.

Privacy policy (English)

Agendador is a personal app that runs only on its owner's own computer to schedule videos on the owner's own YouTube channels. With the owner's Google authorization it uses the YouTube Data API to identify the connected channel, upload videos, set title, description and publish time, check whether a video went live, and delete scheduled videos the owner cancels. All data stays on the owner's computer (local database; credentials in the macOS Keychain). There are no Agendador servers; data is only sent to Google/YouTube to perform the owner's requests. Data is never sold, shared or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked in the app or at myaccount.google.com/permissions.

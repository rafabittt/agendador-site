Política de privacidade do Agendador

Última atualização: 14 de novembro de 2026. Veja também os Termos de uso.

Quem é o responsável

O Agendador é desenvolvido e mantido pela MARCAI TECNOLOGIA LTDA, CNPJ 66.469.940/0001-32 ("Marcai"), responsável pelo tratamento dos dados descritos aqui.

O que é

O Agendador é um aplicativo que agenda publicações nas redes sociais pelas APIs oficiais de cada rede. Hoje ele está em fase de testes: roda apenas no computador da Marcai e é usado só para as contas que a própria Marcai administra. Ainda não é oferecido ao público.

Quais dados usa

Só com a autorização dada pelo titular da conta, no login oficial de cada rede:

  • YouTube (Google): nome, ID e foto do canal; envio de vídeos; título, descrição e horário de publicação; conferência de que o vídeo foi publicado; e remoção ou volta para "privado" de vídeos agendados que forem cancelados.
  • Instagram (Meta): nome de usuário, ID e foto da conta profissional; envio de fotos, carrosséis e vídeos com legenda; conferência de que o post foi publicado e do limite de publicações da conta.
  • TikTok: nome, foto e identificação da conta; quem pode ver e as opções de interação permitidas pela conta (consultadas a cada post, como o TikTok exige); envio de vídeos com legenda e as escolhas feitas por quem posta (privacidade, comentários, dueto, costura e divulgação comercial), ou envio para a caixa de entrada do app do TikTok; conferência de que o vídeo foi publicado.
  • LinkedIn: lista das páginas de empresa que a pessoa administra (nome e ID); envio de textos, fotos, vídeos, documentos e enquetes para essas páginas; conferência de que o post foi publicado.

O app não lê mensagens, comentários, seguidores nem dados de outras pessoas.

Onde os dados ficam

Tudo fica no computador onde o app roda: os posts, os arquivos e o histórico num banco de dados local, e as credenciais de acesso no Chaveiro do macOS. Não existem servidores do Agendador. Os dados só são enviados para a própria rede (Google/YouTube, Meta/Instagram, LinkedIn ou TikTok), para fazer o que foi pedido.

Compartilhamento

O app não vende, não compartilha e não transfere dados para terceiros, e não usa dados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso e apagar os dados

  • No próprio app, em Contas, "Remover" desconecta a conta e apaga o acesso guardado.
  • Google: myaccount.google.com/permissions.
  • Instagram/Facebook: Configurações › Apps e sites (ou Integrações empresariais) › remover o Agendador.
  • TikTok: no app do TikTok, Configurações e privacidade › Segurança › Apps e serviços conectados (ou equivalente) › remover o Agendador.
  • LinkedIn: Configurações › Serviços permitidos.
  • Remover o app do computador apaga todos os dados locais.

Privacy policy (English)

Agendador is developed and maintained by MARCAI TECNOLOGIA LTDA (Brazilian company, CNPJ 66.469.940/0001-32), which is responsible for the data described here. It schedules posts through each network's official API. It is currently in testing: it runs only on Marcai's own computer and is used only for accounts Marcai manages; it is not offered to the public yet.

With the account holder's authorization it uses: the YouTube Data API (channel name, ID and picture; video upload; title, description and publish time; publish check; removing or making private scheduled videos that are cancelled), the Instagram API (professional account username, ID and picture; publishing photos, carousels and videos with captions; publish check and publishing limit), the LinkedIn Community Management API (pages the person administers; publishing text, images, videos, documents and polls to those pages; publish check), and the TikTok Content Posting API (account name, picture and id; the privacy and interaction options available to the account, queried before each post as TikTok requires; uploading videos with captions and the poster's choices for privacy, comments, duet, stitch and commercial content disclosure, or sending them to the TikTok app inbox; publish check). It does not read messages, comments, followers or other people's data.

All data stays on the computer where the app runs (local database; credentials in the macOS Keychain). There are no Agendador servers; data is only sent to the network itself to perform the requested action. Data is never sold, shared or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed in the app (Contas › Remover), at myaccount.google.com/permissions, in Instagram/Facebook settings (Apps and websites / Business integrations), in the TikTok app (Settings and privacy › Security › Apps and services) and at LinkedIn › Permitted services. Uninstalling the app deletes all local data. Contact: contato@tbiglobal.com.br. See also the Terms of Service.
